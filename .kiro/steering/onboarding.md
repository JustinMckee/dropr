# Onboarding Strategy

## Philosophy

First impressions matter. Guide users to their first success quickly and clearly. Show value before asking for commitment. Use progressive disclosure—reveal features as users need them, not all at once. Make onboarding feel like a natural conversation, not a tutorial. Measure success by activation, not completion rates.

## Onboarding Checklist

**Buyer Onboarding:**
- [ ] Landing page optimized for conversion
- [ ] Clear value proposition above the fold
- [ ] Browse drops without signup
- [ ] Signup only required at checkout
- [ ] First purchase flow optimized
- [ ] Post-purchase onboarding (follow curators, set preferences)

**Curator Onboarding:**
- [ ] Application form with clear requirements
- [ ] Application status tracking
- [ ] Welcome email with next steps
- [ ] First drop creation wizard
- [ ] Drop preview and testing
- [ ] First sale celebration

**Activation Metrics:**
- [ ] Buyer activation: First purchase within 7 days
- [ ] Curator activation: First drop created within 14 days
- [ ] Retention: Second purchase/drop within 30 days

**Onboarding Experience:**
- [ ] Progressive disclosure (show features when needed)
- [ ] Contextual tooltips and hints
- [ ] Onboarding checklist visible
- [ ] Skip option available
- [ ] Mobile-optimized flows
- [ ] Accessibility compliant

## Buyer Onboarding Journey

### Stage 1: Discovery (First Visit)

**Goal**: Help users understand what Dropr is and see value immediately.

**Experience:**
1. **Landing Page** - Clear value proposition
   - Headline: "Curated Mystery Drops for Makers & Modders"
   - Subheadline: "Limited releases from verified curators you can trust"
   - Hero image: Featured drop with countdown
   - Social proof: "Join 10,000+ makers discovering unique drops"

2. **Browse Without Signup** - Reduce friction
   - Show active drops immediately
   - Filter by category (keyboards, PC mods, miniatures)
   - View drop details and curator profiles
   - No signup wall

3. **Value Indicators** - Build trust
   - Curator verification badges
   - Drop ratings and reviews
   - Escrow protection messaging
   - "Sold out in 2 hours" social proof

**Success Metric**: 50%+ of visitors view at least one drop

### Stage 2: Interest (Drop Engagement)

**Goal**: Convert interest into intent to purchase.

**Experience:**
1. **Drop Detail Page** - Show full value
   - High-quality images
   - Detailed description
   - Curator profile and history
   - Reviews from previous buyers
   - Countdown timer (creates urgency)
   - Clear CTA: "Buy Now - $49.99"

2. **Curator Profile** - Build trust
   - Bio and expertise
   - Community presence (Reddit, Discord)
   - Past drops and ratings
   - "Follow" button (requires signup)

3. **Social Proof** - Reduce risk
   - "23 people viewing this drop"
   - "15 sold in the last hour"
   - Reviews: "Exceeded expectations!"

**Success Metric**: 30%+ of drop viewers click "Buy Now"

### Stage 3: Signup (Checkout)

**Goal**: Minimize friction at the critical moment.

**Experience:**
1. **Signup at Checkout** - Just-in-time registration
   - "Create account to complete purchase"
   - Email + password (or social login)
   - Auto-fill from browser
   - Clear privacy messaging

2. **Guest Checkout Option** - Reduce abandonment
   - "Continue as guest"
   - Email for order confirmation
   - Optional account creation after purchase

3. **Payment** - Stripe Elements
   - Secure payment form
   - Saved payment methods (returning users)
   - Clear total and breakdown
   - Trust badges (Stripe, SSL)

**Success Metric**: 70%+ checkout completion rate

### Stage 4: First Purchase (Activation)

**Goal**: Complete first transaction successfully.

**Experience:**
1. **Order Confirmation** - Immediate feedback
   - "Order confirmed! Check your email."
   - Order details and tracking
   - Estimated delivery date
   - CTA: "Track your order"

2. **Welcome Email** - Set expectations
   - Order summary
   - What happens next
   - Curator contact info
   - CTA: "Explore more drops"

3. **Post-Purchase Onboarding** - Deepen engagement
   - "Follow this curator for future drops"
   - "Set drop alert preferences"
   - "Explore drops in [category]"

**Success Metric**: 100% order confirmation delivery

### Stage 5: Retention (Repeat Purchase)

**Goal**: Convert first-time buyers into repeat customers.

**Experience:**
1. **Delivery Notification** - Prompt for review
   - "Your order has been delivered!"
   - "How was your experience?"
   - CTA: "Leave a review"

2. **Personalized Recommendations** - Drive discovery
   - "Drops you might like"
   - Based on purchase history
   - Based on followed curators

3. **Drop Alerts** - Re-engagement
   - Email: "New drop from [curator]"
   - In-app: "[Category] drop going live in 1 hour"

**Success Metric**: 30%+ make second purchase within 30 days

## Curator Onboarding Journey

### Stage 1: Application (Interest)

**Goal**: Attract quality curators and set clear expectations.

**Experience:**
1. **Application Landing Page** - Sell the opportunity
   - Headline: "Become a Curator"
   - Benefits: "Monetize your expertise and surplus"
   - Requirements: "Verified makers only"
   - Social proof: "Join 500+ curators"

2. **Application Form** - Gather necessary info
   - Personal info (name, email)
   - Business name (optional)
   - Bio (100-1000 characters)
   - Social links (Twitter, Instagram, Discord, Reddit)
   - Portfolio (1-5 examples of work)
   - Why you want to curate

3. **Application Submitted** - Set expectations
   - "Application received!"
   - "We'll review within 48 hours"
   - "Check your email for updates"

**Success Metric**: 80%+ application completion rate

### Stage 2: Approval (Verification)

**Goal**: Review applications quickly and communicate clearly.

**Experience:**
1. **Admin Review** - Evaluate quality
   - Check portfolio and social proof
   - Verify community presence
   - Assess fit with culture clusters
   - Approve or reject with reason

2. **Approval Email** - Welcome and guide
   - "Congratulations! You're approved."
   - "Here's how to create your first drop"
   - CTA: "Create your first drop"
   - Link to curator guidelines

3. **Rejection Email** - Provide feedback
   - "Thank you for applying"
   - Reason for rejection
   - "You can reapply in 30 days"
   - Appeal process

**Success Metric**: 48-hour review turnaround

### Stage 3: First Drop (Activation)

**Goal**: Help curators create their first successful drop.

**Experience:**
1. **Curator Dashboard** - Clear next steps
   - Welcome message
   - Onboarding checklist:
     - ☐ Complete profile
     - ☐ Create first drop
     - ☐ Set up payouts
   - CTA: "Create your first drop"

2. **Drop Creation Wizard** - Step-by-step guidance
   - **Step 1: Drop Details**
     - Theme (Title with examples)
     - Description (template provided)
     - Category selection
   
   - **Step 2: Pricing & Inventory**
     - Price (required ranges by tier)
     - Inventory count
     - Value expectation (minimum value)
   
   - **Step 3: Images**
     - Upload drop image
     - Image requirements shown
     - Preview before upload
   
   - **Step 4: Timing**
     - Start date/time
     - Duration (24h, 48h, 72h)
     - Countdown preview
   
   - **Step 5: Review**
     - Preview drop as buyers see it
     - Edit any section
     - Submit for review (if moderation enabled)

3. **Drop Preview** - Test before launch
   - "Preview your drop"
   - Share preview link with friends
   - Make edits before going live

**Success Metric**: 70%+ of approved curators create first drop within 14 days

### Stage 4: First Sale (Success)

**Goal**: Celebrate first sale and guide fulfillment.

**Experience:**
1. **First Sale Notification** - Celebrate!
   - Email: "🎉 You made your first sale!"
   - Order details
   - Fulfillment instructions
   - CTA: "View order details"

2. **Fulfillment Guide** - Clear instructions
   - How to mark as shipped
   - Shipping best practices
   - Communication with buyer
   - Tracking number entry

3. **Payout Setup** - Enable earnings
   - "Set up payouts to receive your earnings"
   - Stripe Connect onboarding
   - Bank account verification
   - Payout schedule explained

**Success Metric**: 90%+ of first orders fulfilled within 7 days

### Stage 5: Growth (Retention)

**Goal**: Help curators build sustainable businesses.

**Experience:**
1. **Performance Dashboard** - Show progress
   - Total sales and revenue
   - Drop performance metrics
   - Follower growth
   - Ratings and reviews

2. **Best Practices** - Continuous learning
   - "Tips for successful drops"
   - Case studies from top curators
   - Community forum access
   - Monthly curator newsletter

3. **Next Drop Prompt** - Encourage consistency
   - "Create your next drop"
   - "Your followers are waiting"
   - Suggested drop ideas based on past performance

**Success Metric**: 60%+ of curators create second drop within 30 days

## Onboarding Components

### Onboarding Checklist

```typescript
// components/onboarding/OnboardingChecklist.tsx
interface ChecklistItem {
  id: string;
  title: string;
  description: string;
  completed: boolean;
  action: {
    label: string;
    href: string;
  };
}

export function OnboardingChecklist({ items }: { items: ChecklistItem[] }) {
  const progress = (items.filter(i => i.completed).length / items.length) * 100;
  
  return (
    <div className="onboarding-checklist">
      <div className="progress-bar">
        <div className="progress" style={{ width: `${progress}%` }} />
      </div>
      
      <h3>Get Started</h3>
      <p>{Math.round(progress)}% complete</p>
      
      <ul>
        {items.map((item) => (
          <li key={item.id} className={item.completed ? 'completed' : ''}>
            <input
              type="checkbox"
              checked={item.completed}
              disabled
              aria-label={item.title}
            />
            <div>
              <h4>{item.title}</h4>
              <p>{item.description}</p>
              {!item.completed && (
                <a href={item.action.href}>{item.action.label}</a>
              )}
            </div>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

### Contextual Tooltips

```typescript
// components/onboarding/Tooltip.tsx
export function OnboardingTooltip({
  target,
  content,
  position = 'bottom',
  onDismiss,
}: TooltipProps) {
  return (
    <div className="onboarding-tooltip" data-position={position}>
      <div className="tooltip-content">
        {content}
        <button onClick={onDismiss} aria-label="Dismiss">
          Got it
        </button>
      </div>
      <div className="tooltip-arrow" />
    </div>
  );
}

// Usage
<OnboardingTooltip

  position="bottom"

/>
```

## Best Practices

- Show value before asking for commitment
- Use progressive disclosure (reveal features as needed)
- Make onboarding skippable (don't force it)
- Celebrate small wins (first purchase, first sale)
- Provide contextual help (tooltips, hints)
- Test and optimize each step
- Track drop-off points and iterate
- Personalize based on user type
- Use social proof to build trust
- Make it mobile-friendly
- Ensure accessibility compliance
- A/B test onboarding flows

## Common Mistakes to Avoid

- Requiring signup before showing value
- Overwhelming users with too much information
- Long, mandatory tutorials
- Not celebrating first successes
- Unclear next steps
- No progress indicators
- Forcing users through rigid flows
- Not testing on mobile devices
- Ignoring drop-off analytics
- One-size-fits-all onboarding
